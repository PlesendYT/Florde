# Florde

> **Don't just trust, Understand.**

Florde is a **privacy-first, offline-first AI coding agent** designed to give developers control over their code, AI providers, and tools.

## Features

- Multiple AI providers
- Local AI with Ollama
- Agent-based coding workflows
- File & project access control
- MCP support
- Built-in IDE and terminal
- Local-first project data
- Your own API keys

## Privacy

Florde does not require a Florde cloud for AI requests. You choose where your AI runs and which provider receives your data.

## Tech Stack

- Electron
- JavaScript
- HTML & CSS
- Monaco Editor
- xterm.js
